# Cafetería

## Descripción
Proyecto de una cafetería con información sobre los productos de su carta y sus precios.

## Requisitos
- Git
- Los programas necesarios para ejecutar el proyecto, según las tecnologías utilizadas.

## Instalación
1. Clonar el repositorio.
2. Acceder a la carpeta del proyecto.
3. Preparar el entorno necesario para ejecutar la aplicación.

## Uso
Consultar la carta de productos y sus precios.
